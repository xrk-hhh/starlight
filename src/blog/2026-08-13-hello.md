# 你好，世界

欢迎来到我的博客。这里会记录三类内容：

- **算法复盘**：竞赛与题目中的思路总结，比如 [2048 策略竞技场](/blog/2026-08-10-2048-ai-strategies)里 14 种 AI 策略的进化过程；
- **项目笔记**：从 Java Swing 游戏到 PySide6 桌面应用，把踩过的坑写下来；
- **Web 与性能**：比如这个网站本身是怎么搭出来的。

写博客对我而言是一种"输出倒逼输入"——把一个模糊的 idea 讲清楚，往往比写完代码更难。希望这些记录对你有用。
