# 2048 策略进化竞技场：14 种 AI 与 Bitboard 引擎

[2048 Strategy Arena](https://github.com/xrk-hhh/2048-Strategy-Arena) 是我做的一个"策略竞技场"：14 种 AI 策略在同一套引擎上同台竞技，用 ECharts 实时可视化各自的胜率与分数曲线。

## Bitboard：把棋盘塞进 64 位

2048 棋盘是 4×4，每格最大到 2^17。用每格 4 bit 表示对数刻度，整个棋盘恰好放进一个 64 位整数：

```python
def slide_row(row: int) -> int:
    # row 是 16 bit，每 4 bit 一格
    cells = [(row >> (i * 4)) & 0xF for i in range(4)]
    merged = [c for c in cells if c]
    out = []
    i = 0
    while i < len(merged):
        if i + 1 < len(merged) and merged[i] == merged[i + 1]:
            out.append(merged[i] + 1)
            i += 2
        else:
            out.append(merged[i])
            i += 1
    return sum(v << (j * 4) for j, v in enumerate(out))
```

位运算版本比纯列表操作快一个数量级，这是引擎达到 **74% 胜率** 的基础——搜索深度上去了，胜率自然上去了。

## 14 种策略的进化谱系

- **基准层**：随机、贪心（最高合并）、角落优先——负责给"更强策略"提供对照；
- **启发式层**：单调性、空位数、蛇形布局的加权评估 + 期望最大化（Expectimax）搜索；
- **元层**：遗传算法调参、多策略投票（参谋团）——让策略之间互相学习。

最有意思的发现是：**更强的评估函数未必带来更高的胜率**。参数在遗传算法里"过拟合"到训练盘面后，实际对局反而下滑。最终胜率榜前几名的策略，评估权重都出奇的简单。

## 结论

先跑通基准，再谈优化；可视化是调试策略最好的朋友。
