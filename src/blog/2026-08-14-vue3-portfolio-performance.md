# 从零搭建 Vue3 + Three.js 个人网站：性能优化实录

你正在浏览的这个网站，技术栈是 Vue 3 + TypeScript + Vite + Tailwind CSS 4 + Three.js + GSAP，部署在 GitHub Pages。开发过程中定了一条铁律：**性能优先，克制动画**。分享三个真实的坑。

## 坑一：类型检查根本没生效

最初构建脚本用 `vue-tsc --noEmit`，根 tsconfig 只引用了 node 工程。实测发现：在 `src/` 里故意写一个类型错误，构建依然通过——**src 从未被类型检查**。

修复：根 tsconfig 引用 app + node 两个工程，改用 `vue-tsc -b` 构建模式，并用"故意注入错误必须使构建失败"的双探针验证。

## 坑二：冻结星空

粒子密度按路由分档：首页密、内容页稀、文章页关。上线前验收时发现：从首页切到文章页后，canvas 虽然停止了渲染，却**残留了最后一帧画面**——一整片静止的星空。

修复只有一行：密度切到 0 时 `renderer.clear()` 清掉残留帧。

## 坑三：被盖住的渐变兜底

WebGL 不可用时的 CSS 渐变回退写在 `html` 上，被 `body` 的不透明背景完全盖住。视觉验收（截图 + 视觉模型）才发现。移到了 `body` 上。

## 性能清单

- 粒子 ≤ 1000，运动全部在 vertex shader 里算，CPU 每帧只更新一个 uniform；
- DPR 封顶 2；移动端（<768px）粒子直接关闭；
- 页面不可见暂停渲染循环；尊重 `prefers-reduced-motion`；
- 首屏 JS < 300KB 预算，markdown-it/shiki 只在博客详情页懒加载。
